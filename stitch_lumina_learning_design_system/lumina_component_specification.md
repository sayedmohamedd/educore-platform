# Lumina Learning Component Library

This document defines the comprehensive suite of reusable UI components for the Lumina Learning platform, built upon the established 8px spacing system and modern EdTech design language.

## 1. Buttons & Actions
*   **Primary Button:** Indigo-to-Violet gradient (#6366F1 to #8B5CF6), 14px radius, soft shadow.
    *   *States:* Default, Hover (scale + brightness), Active (scale down), Disabled (opacity 50%), Loading (spinner).
*   **Secondary Button:** Surface-container-high background, text-primary.
*   **Ghost/Tertiary Button:** No background, border-none, text-secondary.
*   **Icon Buttons:** Square 44px, circular options for avatars.

## 2. Form Elements
*   **Text Inputs / Search / Textarea:** 14px radius, #E2E8F0 border, focus ring (#6366F1/20).
    *   *States:* Default, Hover, Focus, Error (Red border + text), Success (Green border), Disabled.
*   **Select / Dropdown:** Custom chevron, menu with 20px radius and soft shadow.
*   **Selection Controls:**
    *   **Checkbox:** Rounded 4px, indigo fill on checked.
    *   **Radio:** Circular, indigo dot center.
    *   **Switch:** Pill-shaped, smooth toggle animation.

## 3. Data Entry & Selection
*   **Filters:** Horizontal chips/badges with 'close' icons for active filters.
*   **Tabs:** Underlined (primary) or pill-shaped (secondary) indicators.
*   **Pagination:** Rounded buttons with active indigo state.

## 4. Feedback & Indicators
*   **Badges:** Small, medium sizes. Colors: Primary, Success, Warning, Danger, Neutral.
*   **Progress Bar:** 8px height, rounded, indigo fill with subtle animation.
*   **Toasts:** Floating bottom-right, 16px radius, icon-based (Success, Error, Info).
*   **Loading Skeletons:** Pulsing neutral-gray blocks for headers, text, and cards.

## 5. Cards (20px Radius, Soft Shadows)
*   **Course Card:** Image top, Category badge, Title, Progress bar, Instructor avatar.
*   **Teacher Card:** Large circular avatar, Bio, Rating, Subject tags.
*   **Statistics Card:** Large numeric value, Icon background, Percentage trend indicator.
*   **Wallet Card:** Gradient background, balance, quick action buttons (Top up/Withdraw).

## 6. Overlays & Layout
*   **Dialogs / Modals:** 24px radius, centered, backdrop blur.
*   **Drawer:** Slides from right, full height, 280px or 400px width.
*   **Accordion:** Collapsible sections with smooth height transitions.
*   **Breadcrumbs:** Chevron separators, current page bold.

## 7. Data Display
*   **Tables:** Clean rows, no vertical borders, sticky header, hover state for rows.
*   **Charts:** Line and Bar charts using the indigo/violet/teal palette.
*   **Empty States:** Illustration-led, centered, clear 'Create' or 'Retry' CTA.

## 8. Navigation & Menus
*   **Dropdowns:** Float above content, 20px radius, hover-highlight on items.
*   **Avatar:** Circular, online/offline status indicators.
